HabitFlow – Habit Tracker

HabitFlow is a modern and responsive habit tracking web application designed to help users build better habits, maintain consistency, and track their daily progress.

Features

- Create, edit and delete habits
- Daily habit check-ins
- Streak tracking
- Progress dashboard
- Search, filter and sort habits
- Charts and activity heatmap
- Dark and light mode
- Export and import data
- Notifications
- Responsive design

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
